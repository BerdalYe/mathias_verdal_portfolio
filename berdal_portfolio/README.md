# Mathias Verdal | Portfolio

My personal portfolio website. It introduces me, links to my profiles and shows the projects I have built.

**Live site:** https://berdal.dev

## Pages

- **Hjem** (`index.html`): short introduction, links to GitHub and LinkedIn, and contact details.
- **Prosjekter** (`projects.html`): project cards with description, tags and a link.

The site is written in Norwegian.

## Projects shown

- **BerdalProductions**: my one-person brand for web projects and apps.
- **Arbeidsdager**: Android app for logging workdays, planning shifts and chatting with your team.

## Tech

Plain HTML and CSS. No frameworks and no build step.

## Project structure

```
berdal_portfolio/
├── index.html      # home page
├── projects.html   # projects page
├── style.css       # all styling
├── script.js       # reserved for future scripts (empty)
├── robots.txt
├── sitemap.xml
└── assets/         # logo, profile picture and project images
```

## Run locally

Open `index.html` in your browser. No install needed.

## Deployment

Hosted on Cloudflare. The domain `berdal.dev` and its DNS are also managed in Cloudflare.
